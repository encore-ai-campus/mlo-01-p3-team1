## 패턴별 식과 대표 선택

날씨마다 PRIMARY와 SUPPORT를 독립 계산합니다. PRIMARY는 V1의 구간·가중치·ceiling 100을 보존하고 SUPPORT는 ceiling 80을 사용합니다.

```text
d_j = max(L_j-x_j, 0, x_j-U_j)
f_j = 100 * max(0, 1-d_j/h_j)
f_mode = 100 if mode == preferred_mode else 0
W_pattern = (ceiling/100) * sum(weight_j*f_j) / 100
PASS_pattern(t) = W_pattern>=t AND f_energy>=core_min
                                AND f_acousticness>=core_min
```

현재 `t=75`, `core_min=20`입니다. 구간 안의 절편은 패턴의 ceiling이며 감점 계수는 `ceiling*weight/100`입니다. 실제 회귀에서 학습한 계수는 아닙니다.

먼저 **핵심 E/A 성분 게이트를 통과한 패턴 중 W가 가장 높은 패턴**을 대표로 선택하고 동점은 `pattern_id` 오름차순으로 정합니다. PRIMARY를 강제로 우선하지 않습니다. 그 대표 점수가 하한 이상이면 후보에 포함하고 하한 미달이면 `CORE_PASS_SCORE_BELOW_THRESHOLD`로 제외합니다. 핵심 게이트를 통과한 패턴 자체가 없을 때만 전체 raw 최고점을 `RAW_MAX_DIAGNOSTIC_ONLY`로 보관하고 후보에서 제외합니다. 대표 점수와 E/A/V/M 성분은 모두 같은 대표 패턴의 값이며 특성별로 유리한 패턴을 섞지 않습니다.

민감도 70/75/80은 각 임계값에서 핵심 게이트와 해당 점수 하한을 모두 통과한 패턴의 존재 여부를 확인합니다. 대표 패턴은 각 경우에 같은 핵심 게이트 우선·최고 W 규칙으로 정합니다. 전체 raw 최고점 패턴 하나의 게이트 실패만으로 다른 정상 패턴까지 제외하지 않습니다.

## 전곡 1개 이상 매칭의 근거

SUPPORT의 다음 다섯 닫힌 상자는 연속 특성 `[0,1]^3`을 모두 덮습니다.

| 조건 | 포함하는 SUPPORT |
|---|---|
| e≥.5, v≥.5, a 전체 | 맑음 |
| e≥.5, v≤.5, a 전체 | 구름낌 |
| e≤.5, v≥.5, a 전체 | 눈 |
| e≤.5, v≤.5, a≤.5 | 흐림 |
| e≤.5, v≤.5, a≥.5 | 비 |

여기서 소문자 `e/a/v`는 원본 0~1 특성이고 대문자 E/A 성분은 변환한 0~100 적합도입니다.

각 상자 내부에서 연속 성분은 모두 100이고 E/A 게이트도 통과합니다. mode 불일치 또는 NULL에서 성분을 0으로 유지해도 `80×.95=76≥75`입니다. 따라서 영역 분할과 내부 점수 하한으로 전곡 매칭을 설명할 수 있습니다. `0/.5/1`의 27개 연속 특성 조합 × mode `0/1/null`의 **81개 경계 사례**는 이 논증을 보조하는 검사이며, 샘플만으로 전체 영역을 증명했다고 주장하지 않습니다.

실제 61,931곡의 합격 후보 합집합도 분모의 ID 집합과 정확히 일치했습니다. fallback 강제 배정·곡별 점수 바닥 올리기는 사용하지 않았습니다. 이 보장은 기획식의 영역 커버리지이며 실제 날씨 적합성의 청취 검증은 아닙니다.

## 정확 연산·부적합·선택 오류 검사

각 패턴을 float64로 먼저 계산해 점수 70/75/80 및 핵심 성분 20의 경계 오차를 진단하고, 모든 원본 소수와 구간을 `Fraction`으로 계산해 합격·동점·대표 성분을 확정합니다. 정확 점수의 직렬화값도 함께 보존합니다. 실제 경계 오차 ID와 패턴별/날씨 합집합 판정 변화는 summary에 있습니다. 분석 정확 연산을 운영 구현 완료로 해석하지 않습니다.

고정 가정 앵커는 특정 날씨에 합격하면서 다른 날씨에 탈락하는지 검사합니다. 맑음 `.8/.1/.8/m1`은 비·눈에 탈락합니다. 구름낌 `.9/.05/.1/m0`, 흐림 `.2/.1/.2/m0`, 비 `0/.95/0/m0`, 눈 `.1/.9/.9/m1`은 각각 해당 날씨에만 합격합니다. 기존 가상 패턴도 함께 보존했습니다.

선택 오류를 잡는 검사는 구름낌 원본 `e=.843, a=.5, v=.53, mode=0`입니다. PRIMARY는 **75.7점**이지만 energy 성분 **19점**으로 탈락하고 SUPPORT는 **75.2점**으로 합격합니다. 코드가 더 높은 raw 점수 패턴 때문에 정상 SUPPORT를 제외하지 않고 후자를 선택하는지 확인합니다. 같은 원본에서 `v=.65`이면 핵심 게이트를 통과한 SUPPORT의 **56점**을 대표로 유지하고 점수 미달로 제외해야 합니다. 이때 핵심 게이트에 실패한 PRIMARY의 75.7점을 대표로 사용하지 않는 반례도 검사합니다. 연속 특성 결측 시 NULL 점수 보류도 검사합니다.
