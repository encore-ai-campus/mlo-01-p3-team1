## 분모·수식

원본 114,000행을 `track_id` 기준 89,741곡으로 분석합니다. 같은 ID의 모든 원본 장르를 합집합으로 보존하고 기존 18개 서비스 장르 매핑을 사용합니다. 오디오 특성·길이는 ID 내 동일하지만 인기도는 720개 ID에서 충돌하므로 추천 점수·정렬에 사용하지 않습니다.

메타데이터·양의 길이·유효 원본 특성·mode 0/1·양의 tempo·서비스 장르 연결을 확인한 **61,931곡**을 공통 분석 분모로 사용합니다. 기존 산정안의 61,934곡에는 tempo=0인 3곡이 포함되며 새 분석에서는 보류했습니다.

각 연속 특성의 값 `x`, 목표 구간 `[L,U]`, 감점 폭 `h`에 대해:

```text
d(x,L,U) = max(L-x, 0, x-U)
component = 100 * max(0, 1 - d/h)
mode_component = 100 if mode == preferred_mode else 0
W = sum(weight_j * component_j) / 100
PASS = (W >= 75) AND (energy_component >= 20)
                    AND (acousticness_component >= 20)
```

5개 날씨의 점수를 서로 정규화하거나 차감하지 않습니다. 같은 곡의 다중 날씨 통과를 허용합니다. 이 계산상의 독립성은 날씨별 점수의 통계적 무상관을 뜻하지 않습니다.

현재 한 지역의 유효한 최신 날씨 분류가 바뀌면 새 목록 버전을 만드는 정책을 메타데이터로 기록합니다. 예보 구간별 점수 평균은 사용하지 않으며 실제 갱신·API·재생 전환은 이 분석에서 실행하지 않습니다.

PTY2/6은 기존 비·눈 통과 후보의 교집합을 사용합니다. 여섯 번째 독립 날씨 모델을 학습하거나 새 가중치를 만들지 않습니다. 어댑터 CSV에는 비·눈 각각의 점수와 성분을 보존하고 `min(비 점수, 눈 점수)` 내림차순·ID 오름차순으로 정렬합니다. 이 정렬은 초기 제안입니다. 교집합·전체 speed·AUTO 무보컬 True·slow/medium 추가 수량과 시간은 `summary.json`의 `mixed_adapter`에서 확인할 수 있습니다. 독립 5개 날씨 통과 분포에는 어댑터를 추가하지 않습니다.

전체 날씨 후보에는 무보컬·특정 speed 필터가 없습니다. `summary.json`에 instrumentalness 자동 True 추가 후와 예시 speed 추가 후의 수량·시간을 별도로 기록합니다. 검수값이 없는 CSV에 `.8 이상=True`, `.2 미만=False`, 그 사이 UNKNOWN의 자동 보조 판정을 적용했으며 실제 무보컬 청취 확정은 아닙니다.

## 수치 경계와 정렬

먼저 NumPy float64로 계산하고, 점수 70/75/80 또는 핵심 성분 20에 `1e-8` 이내로 가까운 항목을 원본 소수 문자열의 `Fraction`으로 재검사합니다. 75점 기준에서 구름낌 11곡, 눈 8곡의 통과 판정이 교정되었습니다. 눈은 핵심 성분의 정확한 20점 경계에서도 부동소수 오차가 발생했습니다. 세부 ID·교정 전 값·정확한 분수는 `summary.json`에 있습니다.

추가로 전체 곡의 정확 성분값과 점수를 유리수로 계산하여 모든 하한 판정을 대조했습니다. 수학적 동점이 94.99999999999999/95처럼 갈리는 문제를 없앤 뒤 점수·ID로 정렬했습니다. 이는 분석 재현 방식이며 운영용 숫자·저장·정확 연산 계약을 구현한 것은 아닙니다.

## 정확 180분 예시의 검증과 한계

정렬 후보 상위 200개부터 탐색하고 필요 시 두 배씩 확대하는 구조입니다. 이번에는 다섯 날씨 모두 첫 200개 범위에서 해를 찾았습니다. bitset 0/1 subset sum으로 `10,800,000ms`를 정확히 맞추며 32곡 단위 checkpoint와 블록 재구성을 사용합니다. 비·눈 예시는 policy의 slow/medium 조건을 적용하고 다른 날씨는 모든 speed를 허용했습니다. 예시는 모두 보컬 허용입니다.

| 날씨 | 전체 통과 후보 | 정확 180분 예시 곡 수 |
|---|---:|---:|
| 맑음 | 35,636 | 49 |
| 구름낌 | 18,371 | 46 |
| 흐림 | 11,748 | 45 |
| 비 | 8,842 | 44 |

모든 예시의 선택곡은 정확한 W=100입니다. 따라서 곡 시간으로 가중한 평균 점수 `Q=sum(duration_ms*W)/sum(duration_ms)`는 100이며, 점수의 전역 상한 100에 도달했다는 의미에서 이 Q 목적의 최적성은 입증됩니다. 시간 오차는 0입니다. **동점 집합 전체의 ID 사전순 최적성은 입증하지 않아 `tie_optimality=NOT_PROVEN`으로 기록합니다.** 아티스트 다양성·청취 흐름·실제 영상 길이·음원 권한·재생 가능성은 이 최적성 증명에 포함되지 않습니다.
