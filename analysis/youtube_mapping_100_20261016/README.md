- 사용자 요청: 기존 47곡 외 추가 100곡 검수·등록. YouTube 더보기의 공식 정보와 원본 CSV를 대조하며 전곡 청취를 필수로 하지 않음.
- 범위: 로컬 영상 연결 레지스트리. 원본 음악·날씨 점수·전체 추천 후보·불변 선곡표는 변경하지 않음.

## 선정과 근거

`selection.json`은 현재 GENERAL 카탈로그에서 기존 외부 승인 47곡을 제외한 목록입니다. 장르 그룹이 있고 90~480초인 비명시적 곡 중 원본 CSV 인기도 상위 후보를 대상으로, 다섯 날씨의 현행 W≥75 조건을 통과한 곡을 순환 선정했습니다. 최초 목표는 날씨별 20곡씩 100곡이며 뒤 100곡은 연결·버전·행사곡 문제의 대체 후보입니다. 인기도는 원본 데이터의 값이며 현재 YouTube 인기나 실제 서비스 추천 빈도를 뜻하지 않습니다.

`part1/2/3-input.json`의 곡 ID는 서로 겹치지 않습니다. 팀별 목표는 34/33/33곡이며 실제 확보 영상 ID만 조사합니다. 검색 결과와 YouTube의 공식/Topic/레이블 곡 설명·아티스트·앨범·제공사·길이를 대조합니다. 비밀번호·쿠키·API 키·LLM·미디어 다운로드·내부 검색 API는 사용하지 않습니다.

## 정보 일치와 재생을 구분

이번 매핑 검수의 정보 점수는 곡명 35·아티스트 35·앨범 15·길이 15점의 합입니다. 이는 검수 우선순위용 규칙 점수이며 동일 음원일 확률이나 음악 추천 점수가 아닙니다. 확인하지 못한 앨범은 미확인으로 남기며 점수를 부여하지 않습니다. 공식 설명의 동명이곡·서로 다른 편집/녹음·리믹스/라이브/커버·주 아티스트 충돌은 단순 합계로 통과시키지 않습니다. 리마스터·합본/재발매도 근거와 버전 차이를 따로 확인합니다.

원본 길이 d초와 영상 길이 차이는 현행 `min(60, max(12, d*0.12))`초 이내인지 확인합니다. 다른 길이를 맞추려고 원본 `duration_ms`를 변경하지 않습니다. 대체 영상도 같은 기준으로 검수합니다.

공개 watch HTML의 `OK`와 KR 제공 메타데이터는 그 확인 시점의 공개 정보입니다. 실제 브라우저 PLAYING·시간 진행·전곡 청취·물리 스피커 소리·사용자 Chrome의 Premium을 증명하지 않습니다. 짧은 native 재생 관측은 별도 근거에 기록하며, 관측한 항목만 현행 외부 재생 승인 함수에 전달합니다. iframe 승인은 별도이며 이번 작업으로 자동 부여하지 않습니다.

공개 설명의 가사·홍보문구 전문은 보관하지 않습니다. 원곡 식별에 필요한 사실 정보와 짧은 근거만 저장합니다. 유사도 점수가 높아도 실제 확인하지 않은 내용을 만들어 기록하지 않습니다.

## 자료와 적용

- `baseline.json`: 적용 전 기존 레지스트리·카탈로그 요약. 비밀 접근 코드는 포함하지 않음.
- `part*-research.json`: 팀별 원곡·영상·버전·길이·근거·실제 재생의 분리 기록.
- `part*-metadata*.json` / `part*-public-*.json`: 공개 페이지 확인 근거. 실제 파일명은 팀별 산출물에 따름.
- [추가 100곡 등록 CSV](./youtube-additional-100-mappings.csv): 100곡 검수 기록용 UTF-8 BOM 내보내기. 현재 등록 API 입력 형식과 다르며 직접 재등록하지 않음.
- [최종 100곡 검수](./final-100-reviewed.json): 곡 식별·영상·항목 점수·짧은 재생 시간·판정 한계를 보존한 공유 정본. 전체 점수 특성·설명 발췌·raw DOM은 제외.
- [검증·적용 결과](./verification.json)·[실행 중 API 재조회](./live-api-readback.json): 실제 로컬 저장과 대시보드 공급 API 확인.
- [root 시간 진행 관측 · 로컬 보관](../../docs/development/music/YouTube_수집자료_공유와_로컬보관.md#youtube_mapping_100_20261016) (`analysis/youtube_mapping_100_20261016/root-native-progress.json`)·[첫 곡 교차 확인 · 로컬 보관](../../docs/development/music/YouTube_수집자료_공유와_로컬보관.md#youtube_mapping_100_20261016) (`analysis/youtube_mapping_100_20261016/root-first-track-crosscheck.json`): 추가 UI 관측. 팀별 0초 초기 관측은 최종 재생 근거로 사용하지 않음.

## 최종 결과

추가 고유 곡 100개·고유 영상 100개를 등록하고 외부 재생 승인했습니다. 맑음/구름낌/흐림/비/눈 선정 분모는 각각 20곡이며, 기존 47곡과 곡 ID·영상 ID가 겹치지 않습니다. 기존 47곡의 레지스트리 값은 모두 보존했고 누적 외부 승인 147곡·iframe 승인 11곡입니다. 100곡 모두 1초 이상의 실제 native 재생 시간 진행과 원곡 길이 허용 범위를 확인했습니다. 전체 곡 완주·물리 음향·Premium·추가 100곡 iframe 검수를 뜻하지 않습니다.

정보 점수는 100점 36곡·85점 64곡입니다. 앨범 미확인·컴필레이션 또는 판본 차이는 0점으로 남겼습니다. 독립 감사에서 Atlantis의 Expanded Edition과 Everybody Wants To Rule The World의 Super Deluxe Edition이 기본 앨범 확인만으로 100점이 된 두 건을 찾아 정본에서 85점으로 정정했습니다. 팀별 최초 조사 파일은 이력이며 최종 판정은 `final-100-reviewed.json`입니다.

96곡은 공개 국가 목록의 KR 포함을 확인했고 4곡은 해당 목록을 확보하지 못해 `null`로 보존했습니다. 네 곡도 정상 브라우저의 공식 정보·길이·짧은 재생은 확인했으나 KR 제공 메타데이터까지 확인했다고 표시하지 않습니다. 공개 HTTP 429 후 추가 직접 요청을 중단했으며 쿠키/프록시·내부 API 등으로 우회하지 않았습니다. 네 곡은 최종 JSON에서 `korea_in_available_countries=null`로 식별합니다.

Feliz Cumpleaños Ferxxo는 공식 설명에 생일 행사 근거가 있어 이번 등록을 보류하고 같은 CLOUDY의 Paloma Faith 곡으로 교체했습니다. 원본 GENERAL 판정은 수정하지 않았으며 수동 분류 후속 검수 대상으로 남겼습니다.

CSV 후보 등록 후 기존 `verify_native_mapping`으로 각 곡의 확인 근거·실제 관측 길이를 별도 저장했습니다. 음악 카탈로그 86,485곡과 해시·추천 정책·불변 결과는 보존했습니다. 실행 중 조회 API는 HTTP200, 전체 86,485·검수 완료 147·미연결 86,338을 반환했습니다. `native-queue-domain-validation.json`의 100/100은 큐 생성 함수의 결과이며, YouTube가 한 임시 목록에서 100곡 전부를 수용·완주했다는 뜻이 아닙니다.

Git 제외 SQLite는 `.local-preview-logs/youtube-mappings.sqlite3`이며, 적용 전 일관된 백업을 `.local-preview-logs/youtube100/registry-before.sqlite3`에 보관했습니다. 운영자 접근 코드나 백업 DB는 공유/커밋하지 않습니다. 2026-10-19 공유 CSV는 검수 기록 전용 형식으로 정제했습니다. 당시 revision=0인 등록 CSV 원본과 그 해시는 로컬 백업/verification.json에 보존합니다. 공유 CSV를 등록 API에 바로 넣으면 CSV_HEADERS_INVALID로 거절됩니다. 다른 환경의 등록에는 해당 환경의 최신 revision 조회·별도 후보 입력 작성·독립 재생 검수가 필요하며 과거 승인을 자동 복제하지 않습니다.

원래 GENERAL 전체 후보를 이번 100곡 또는 누적 승인 목록으로 제한하지 않습니다. 미연결 추천곡이 포함될 때 기존 대시보드의 준비 수·부분 재생 안내는 계속 적용됩니다. 이 자료는 계정에 저장된 YouTube 재생목록이나 AWS 운영 발행을 뜻하지 않습니다.
