공개 배너·측정 API 시험 수동 시험

시험용 guest·배달로 공개 광고 API를 호출합니다. 배너 확인과 재확인은 자동으로 측정하지 않습니다. 아래 시험 버튼만 이벤트를 전송하며 실제 고객에게 노출되는 화면은 아닙니다. 시험 배달은 노출·클릭 집계와 토큰 합계에 반영되지 않습니다.

처음에는 상단에서 방문자 문맥을 만드세요. 통신 실패 뒤에는 같은 발급 키로 재시도합니다. 별도 새 배달은 [시험 배너 비우기] 후 요청하세요. 표시 중에는 같은 배달을 1초마다 재확인하며 서버의 표시 유효 시각을 넘기면 배너를 숨깁니다. 배달 수명 30분과 표시 재확인 3초는 서로 다른 기준입니다.

아직 공개 배달을 요청하지 않았습니다.

노출 시험은 이미지가 화면에 50% 이상 연속 1초 보인 뒤 가능합니다. 클릭 시험은 외부 링크로 이동하지 않고 CLICK 판정만 확인합니다. is_test=true 배달의 측정 제외 동작을 확인하며, 예산 소진·초과 판정은 별도 자동 테스트에서 검증합니다.
