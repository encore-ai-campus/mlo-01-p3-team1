# 광고 로컬 화면과 프레젠테이션 수정 가이드

- 작성일: 2026-10-16
- 수정일: 2026-10-16
- 브랜치: `feature/ad-logic`
- 적용: AD-03 관리 화면의 로컬 확인 도구. 정식 화면·공유 인증 수용과 구분합니다.

## 1. 이번 구현

사용자 요청에 따라 이 컴퓨터에서 광고 API를 제어하는 화면을 만들고, 개발 총괄이
이후 프레젠테이션 계층(HTML·CSS·문구·브라우저 동작)을 직접 고칠 수 있도록 분리했습니다.
발표용 슬라이드나 별도의 운영 관리자 서비스를 추가한 것은 아닙니다.

기존 [임시 도구](./임시_광고_관리_도구.md)의 접근 코드·시험 guest·MongoDB·5분 검증을
사용합니다. 목록/위치·상태 필터/페이지, 이미지 업로드, 광고 등록·수정·수동 중단,
실제 서버 집계 요약, PC·모바일 미리보기를 연결했습니다.
미리보기와 로컬 시험 배달은 운영 노출·클릭/사용 토큰을 늘리지 않습니다.

광고·이미지 원본·광고 로그는 MongoDB에 저장합니다. PostgreSQL 광고 로그 연결은 없습니다.
공유 ADMIN/guest 규격은 2026-10-16 사용자 확인으로 미수령이며 기존 어댑터 경계를 유지합니다.
음악·피드백 화면, 공개 메인 배너, 재개·삭제, 업종 태그/매칭은 이번 구현에 추가하지 않습니다.

## 2. 실행과 확인

현재 작업 PC에는 Python 가상환경과 시험용 mongod 실행 파일이 준비되어 있습니다.
다른 PC는 [백엔드 안내](../../../ad-server/backend/README.md)의 환경 준비부터 진행합니다.
저장소 루트 PowerShell에서 다음을 실행합니다.

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONIOENCODING='utf-8'
.\ad-server\backend\.venv\Scripts\python.exe .\ad-server\backend\sandbox.py --start-mongo
```

1. 일반 Chrome 또는 Edge 주소창에 `http://127.0.0.1:8001/dev/ads/`를 직접 입력합니다.
2. 실행 터미널에 표시된 `.local/ads-sandbox/access.txt`의 코드를 로그인 입력란에 넣습니다.
3. 광고 이미지를 선택하고 [선택한 이미지 업로드]를 누릅니다. 제목·HTTPS 링크·위치·KST 기간·우선순위를 입력합니다.
4. 공개 제공 후보까지 확인하려면 일일/총 예산을 직접 함께 입력합니다. 미설정 저장은 가능하지만 공개 부적격입니다.
5. [PC·모바일 미리보기]로 서버 입력 검증과 배너 외형을 확인하고 [광고 등록]으로 저장합니다.
6. 하단 [개발 환경 · 예산 검증]을 열어 수동 검증하거나 5분 작업을 기다립니다. 목록 [수정]/[수동 중단]으로 제어합니다.
7. 종료는 실행 터미널의 Ctrl+C입니다. 재실행하면 접근 코드가 바뀌고 저장 데이터는 남습니다.

기본 실행은 `127.0.0.1:8001`, 전용 MongoDB는 `127.0.0.1:27019`의 `ads-rs`,
DB는 `ads_sandbox_dev`입니다. 직접 기동한 DB만 종료하며 기존 서버를 재설정/중단하지 않습니다.
다른 서버가 포트를 사용한다면 해당 프로세스를 임의로 종료하거나 운영 URI를 넣지 않습니다.
공유 `.env`는 읽지 않고 `is_test=true`를 유지합니다. 접근 코드·쿠키·서명 proof를 Git/문서에 넣지 않습니다.

2026-10-16 로그인403을 수정했습니다. 기존 HTTP 헤더와 HTML meta의 `no-referrer`가
일반 폼 POST의 Origin을 null로 만드는 설정 충돌이 원인이었습니다. 내장 브라우저 제한이라는
이전 진단은 정정합니다. 로컬 도구 두 곳을 `same-origin`으로 맞춰 정상 출처 정보를 유지하며,
CSRF/Origin·서명 쿠키·loopback guard는 그대로 검사합니다. null·외부 출처·다른 포트는 계속403입니다.
Codex 내장 브라우저에서 실제 로그인→목록·편집 불러오기→PC/모바일 미리보기→수동 예산 검증을
확인했습니다. 일반 Chrome/Edge의 전체 CRUD 수용은 별도이며 이 성공을 공유 인증 검증으로 확대하지 않습니다.
같은 오류 화면이 남으면 새로고침으로 POST를 재전송하지 말고 `/dev/ads/`를 다시 엽니다.
서버 재시작 후 접근 코드는 access.txt에서 다시 확인합니다.
기술 근거는 [MDN Referrer-Policy](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Referrer-Policy)의 Origin 설명을 참고합니다.

## 3. 개발 총괄의 수정 위치

아래 경로는 저장소 루트 기준이며 파일 링크로 바로 열 수 있습니다.

| 수정 대상 | 파일 | 적용 방식 |
|---|---|---|
| 브랜드·제목·설명·빈 목록·로그인 안내 | [content.json](../../../ad-server/backend/presentation/ads/content.json) | UTF-8 JSON 문자열을 수정하고 새로고침. HTML은 자동 이스케이프 |
| 관리 화면 영역/폼 순서 | [ads_sandbox.html](../../../ad-server/backend/templates/ads_sandbox.html) | HTML 수정 후 새로고침 |
| 접근 코드 로그인 배치 | [ads_sandbox_login.html](../../../ad-server/backend/templates/ads_sandbox_login.html) | HTML 수정 후 새로고침. form action·CSRF·access_code 유지 |
| 색·간격·너비·반응형 | [ads.css](../../../ad-server/backend/presentation/ads/ads.css) | 상단 `:root` 변수와 media query 수정 후 새로고침 |
| 입력/테이블·버튼·미리보기·공개 API 시험 동작 | [ads-page.mjs](../../../ad-server/backend/presentation/ads/ads-page.mjs) | DOM 연결을 함께 확인하고 새로고침 |
| API 경로·CSRF·멱등·오류 표시 | [ads-api.mjs](../../../ad-server/backend/presentation/ads/ads-api.mjs) | `routes`에 API 경로 집중. 전송 계약 변경 시 서버 담당과 대조 |
| KST 입력/UTC 변환·시각 표시 | [time.mjs](../../../ad-server/backend/presentation/ads/time.mjs) | 브라우저 OS 시간대와 독립. 변경 시 자정·밀리초 왕복 검증 |
| 화면 문구 주입·허용 에셋 제공 | [ads_sandbox.py](../../../ad-server/backend/api/ads_sandbox.py) | Python 변경은 서버 재시작 필요 |
| 로컬 화면 경로 | [sandbox_urls.py](../../../ad-server/backend/config/sandbox_urls.py) | sandbox 전용. 일반 URLconf에는 넣지 않음 |

예를 들어 주색은 CSS의 `--blue`, 글자는 `--ink`, 바탕은 `--bg`,
전체 너비는 `--page-width`, 모서리는 `--radius`에서 바꿉니다.
문구 JSON은 문자열만 사용하고 키를 유지합니다. JSON에 HTML·서버 설정·계정·예산 정책을 넣지 않습니다.
필드 이름/버튼 문구와 상태 설명 중 동작과 붙어 있는 것은 HTML 또는 ads-page.mjs에 있습니다.

sandbox 설정은 파일 시스템 템플릿 로더를 사용하므로 HTML도 다음 요청에서 다시 읽습니다.
CSS/MJS/이미지는 허용 목록으로만 제공하고 no-store를 적용합니다. 변경 후 새로고침하면 반영됩니다.
문법이 잘못된 JSON/Python은 오류가 되므로 정상처럼 숨기지 않고 수정/원복합니다.
패키지 설치·프런트엔드 빌드·CDN·외부 웹폰트가 추가로 필요하지 않습니다.

## 5. 화면 교체 시 유지할 연결

화면 HTML의 `id`는 ads-page.mjs와 연결됩니다. 배치/클래스만 바꿀 때는 id를 보존하고,
id를 바꾸거나 영역을 제거할 때는 연결 코드도 함께 수정합니다.

| 영역 | 주요 연결 |
|---|---|
| 목록/요약 | `ad-rows`, `list-empty`, `filter-form`, `filter-placement`, `filter-status`, `page-prev/next`, `count-*`, `today-impressions/clicks/tokens`, `summary-status` |
| 등록/수정 | `ad-form`, `title`, `placement`, `priority`, `link-url`, `starts-at`, `ends-at`, `image-file`, `upload-image`, 숨김 `asset-id`, `asset-info/image`, `daily/total-budget`, `save-ad`, `new-ad` |
| 미리보기 | `preview-ad`, `preview-empty/section/description`, `preview-desktop/mobile`, 각 image/heading |
| 실행 진단 | `worker-dot/status/detail`, `refresh-policy`, `global-message`, `form-message`, `logout` |
| 공개 시험 | `public-panel`, `test-*`, `provide-ad`, `reconfirm-ad`, `clear-delivery`와 기존1초 재확인/가시성 처리 |

관리 API 호출은 `GET /api/admin/ads`, `GET /api/admin/ads/summary`,
`POST /api/admin/ad-assets`, `GET /api/admin/ad-assets/{asset_id}`,
`POST /api/admin/ads`, `PUT /api/admin/ads/{ad_id}`,
`POST /api/admin/ads/{ad_id}/stop`, `POST /api/admin/ads/preview`입니다.
공개 시험은 기존 `/api/ads`, `/api/ad-deliveries/{delivery_id}/image`, `/api/ad-events`를 사용합니다.
정확한 필드/오류는 [화면·API 계약](../../handoff/ads/01_광고_화면_API와_측정_계약.md)을 따릅니다.

- 변경 요청은 CSRF, same-origin cookie, version, 필요한 Idempotency-Key를 유지합니다. 통신 실패 재시도는 같은 키를 사용합니다.
- 저장한 광고 문구는 textContent로 표시합니다. HTML 삽입/임의 외부 스크립트/CDN으로 바꾸지 않습니다.
- 예산은 양의 두 값 쌍이고 기본값을 만들지 않습니다. 브라우저 정확도 상한을 넘는 기존 정수는 수정/중단을 막아 원본을 보존합니다.
- 게시 시각은 KST로 입력하고 UTC로 전송합니다. 편집하지 않은 기존 UTC 시각은 보존합니다.
- 중단을 수정으로 해제하거나 재개/삭제를 추정해서 붙이지 않습니다. 미리보기/새로고침을 측정 이벤트로 보내지 않습니다.
- 부분/대기/오래된 집계를 실제0과 구분하고 서버의 status/as_of/coverage 해석을 유지합니다.

정식 React 화면으로 옮길 때는 이 화면의 구성·API 호출·상태 처리를 옮기고 공유 인증 규격을 연결합니다.
`SandboxMiddleware`, sandbox ADMIN/guest, 접근 코드, 로컬 이미지 주소 변환을 운영 인증으로 가져가지 않습니다.
일반 URLconf·배포 설정·공유 사용자 DB는 이번 구현으로 변경하지 않았습니다.

실행 결과는 [광고 개발 검증 기록](../../acceptance/광고_개발_준비_검증.md)의
2026-10-16 로컬 프레젠테이션 절을 따릅니다. 단위/API, HTTP와 브라우저 외형의 근거를 구분합니다.
시안의 UI가 존재한다는 이유만으로 AD-03/AD-04/I-05 전체를 완료 처리하지 않습니다.
공유 인증, 일반 브라우저 버튼 수용, 공개 화면 가시성/중단3초, 운영 배치/AWS/복구는
[남은 작업 목록](./광고_남은_작업과_연결_계획.md)에 유지합니다.
