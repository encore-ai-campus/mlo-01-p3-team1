## 후속 정정 — 기존 사용자 대시보드 연결

기존 `PublicPage`를 유지하고 곡별 YouTube 검색/검증 영상 링크와 전곡 네이티브 임시 목록 연결을 추가했습니다. 새 일반 test Catalog를 기존 Django 로컬 추천 API/worker에 적재하고47곡·177분32.228초 결과를 실제 화면에서 확인했습니다. 영상 매핑은0/47로 전체 연결을 보류합니다. 별도의 네이티브2곡 시험에서는 광고를 포함한 다음 곡 자동 전환을 확인했으며 전체47곡/3시간 검증과 구분합니다.

현행은 [기존 대시보드 연결 라우팅](./기존_대시보드_YouTube_연결_라우팅.md)·[새 수용 기록](../acceptance/기존_대시보드_YouTube_연결_검증_20261016.md)을 따릅니다. 이전8003 도구는 주 사용자 화면이 아니며 후속 운영 네이티브 연결에 삽입 가능성을 필수 조건으로 요구하지 않습니다. 아래 관측/자동검증/미연결 표현은 최초 보조 도구 당시의 범위로 보존합니다.

## 인터페이스와 버전

데이터 담당이 `analysis/weather_music_20261016/general/examples/{WEATHER}_180min.csv`와 판정/manifest를 공급합니다. 재생 담당의 `PlaylistStore.source/playlist`가 원문을 `source_fields`에 보존하고 시즌 상태·영상 매핑·양의 길이·해시를 검사합니다. 모드·판정 누락을 자동 GENERAL이나 READY로 만들지 않습니다.

조회는 `GET /api/config`, `GET /api/playlists`, `GET /api/playlists/{weather}`입니다. 매핑은 `POST /api/mappings/import`로 현재 `expected_mapping_version`·같은 Origin·로컬 nonce를 확인해 원자 저장합니다. 선택 검색은 서버 키와 nonce·로컬 출처 확인이 필요하며 검색 결과는 CANDIDATE입니다. key/nonce 실값을 문서에 복사하지 않습니다.

미확정 단일 사전 시험과 확정된 일반 큐는 별도 상태로 동작합니다. 새 매핑이 실행 중 큐를 바꾸지 않고 다음 큐 준비에 반영되며, 새로고침 복원도 버전·ID를 대조한 뒤 사용자 시작을 기다립니다. 시즌 정책 변경은 새 버전/사이클에 적용하고 원본·점수·과거 결과는 보존합니다.
