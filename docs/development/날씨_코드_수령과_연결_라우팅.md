## 4. .env 인계 위치

사용자가 넣으실 위치: `C:/Users/Playdata/Documents/ChatGPT/3th/weather/.env`.
설정 이름은 [현재 날씨 .env.example](../../pipeline/weather/.env.example)을 참고합니다.

현재 코드는 `.env`를 자동으로 읽지 않고 프로세스 환경변수를 사용합니다. 파일 배치만으로 실행 설정이 적용되지는 않으며 실행 시 서비스 환경 또는 별도 로더 연결이 필요합니다. 이번에는 로더를 추가하거나 실제 `.env`를 생성/수정하지 않았습니다. `weather/.gitignore`가 해당 파일을 제외합니다.

- 수집: KMA_API_KEY, KAFKA_BOOTSTRAP, topic·상태/로그 경로.
- Spark: SPARK_MASTER, CHECKPOINT_PATH, Kafka·MongoDB writer, Driver·실행 모드.
- 조회/지역 매핑: PostgreSQL DSN 또는 PG* 설정, MongoDB reader.
- 관리자 발행: MongoDB publisher, ES_URL/WEATHER_INDEX, 별도 로그 ES 설정.

reader/writer/publisher 자격증명과 주소·TLS/CA·DB/컬렉션·권한은 INF 확인이 필요하며 광고 계정을 임의 재사용하지 않습니다. 실제 비밀값은 문서에 기록하지 않습니다.
