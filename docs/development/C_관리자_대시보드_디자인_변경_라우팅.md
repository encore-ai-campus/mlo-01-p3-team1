## 시안과 실제 데이터의 차이

- 시안의 곡·집계 숫자·날씨형 테마 예시는 실제 운영 값이나 새 음악 정책으로 채택하지 않습니다. 테마 선택지는 실제 `/api/recommendation-options` 응답을 사용합니다.
- 음악 검수 목록 API는 장르와 전체 곡명 검색을 제공하지 않습니다. 없는 장르 열을 채우지 않고, 검색은 **현재 페이지의 곡명/아티스트** 필터임을 표시합니다. 보컬의 미검수와 보컬 유무를 구분합니다.
- 음악 카드 값은 readiness의 등록·검수 승인·추천 적격·준비 카탈로그 수입니다. 전체 검수 대기 수를 추정하지 않습니다. readiness 조회는 목록과 독립적으로 진행하고 실패를 표시합니다.
- YouTube summary의 verified는 외부 또는 삽입 검수 완료를 뜻하므로 카드에도 이를 표시합니다. 전체 외부/삽입 승인 수를 임의로 만들지 않습니다. 행별 상태는 각각의 mapping 상태로 구분합니다.
- 제외 이력 API에는 전체 집계가 없으므로 카드는 **현재 페이지 기준**으로 명시합니다. 곡명 전체 검색을 가장하지 않고 서버가 지원하는 곡 ID 검색을 사용합니다. 종료일은 KST 미포함 계약을 유지합니다. 이전/다음은 실제 cursor로 이동합니다.
- 이미지 숫자/페이지 링크를 하드코딩하지 않습니다. 기존 API·모델·DB/큐·추천 점수/시간/검수 정책은 변경하지 않습니다. 새 운영 저장·외부 API 호출은 없습니다.

## 검증·인계

- TypeScript 검사 통과, 프론트 Vitest 52건 통과, Vite 빌드 통과.
- `node scripts/admin-dashboard-smoke.cjs`: Playwright의 **모든 API를 격리 응답으로 대체**하고 세 관리자 페이지를 1536×1024/390×844로 검증합니다. 음악 검수 expected_revision/근거, CSV 등록·원본 참조 전달·카탈로그 발행, 상태/페이지 검색, 제외 이력 상세/행동 필터/읽기 전용, YouTube 외부·삽입 독립 상태와 외부 검수 요청, JS 오류/모바일 가로 넘침을 확인합니다.
- 검증 캡처는 Git 제외 `.local-preview-logs/admin-dashboard-20261019/`에 있습니다. 테스트 이미지의 숫자·곡은 검증용이며 앱의 실제 데이터 공급자가 아닙니다. 실제 운영 검수·발행·피드백 변경을 실행하지 않습니다.
- 남은 연결: B 관리자 API/권한 및 INF 운영 환경에서 실제 조회 수용, 긴 곡명/대용량·readiness 지연, 운영 SSO 연결과 영상 재생 관측은 별도입니다. 이번 격리 UI 검증을 운영 저장/재생 성공으로 표시하지 않습니다.

사용자 확인에서 광고 메뉴는 오른쪽, 새 관리 메뉴는 로고 옆에 배치되고 로고 색상·활성 밑줄도 달랐습니다. `AdminLayout.tsx`의 `AdminHeader`를 분리하고 `AdsAdmin.tsx`도 같은 컴포넌트를 사용하도록 연결했습니다. 네 페이지의 로고·관리자 배지·우측 메뉴/계정·로그아웃 DOM과 CSS를 통일했습니다. 로고 전체 남색, 활성 메뉴 파란색, 밑줄 없음과 본문 제목·설명의 여백을 광고 관리 기준으로 맞췄습니다. 활성 메뉴가 바뀌어도 글자 굵기로 메뉴 너비가 변하지 않게 했습니다. 로그아웃의 SSO `logout_url` 처리와 페이지별 API·권한은 유지합니다.
