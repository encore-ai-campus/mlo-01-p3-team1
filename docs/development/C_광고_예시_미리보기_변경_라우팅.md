사용자 요청에 따라 저장소의 [광고 예시 원본](../assets/ad-examples/) 두 장을 `frontend/public/ad-examples/`에 동일 바이트로 복사했습니다. [Banner.tsx](../../frontend/src/features/ad-banners/Banner.tsx)는 개발 서버에서만 `/?ad_preview=1`일 때 상단 1536×120, 하단 1536×104 예시를 보여주고 쿠팡 메인 HTTPS 링크를 엽니다. 안내 화면이 열려 있으면 배너를 가리고, 상단 준비 뒤 하단을 표시하는 기존 화면 순서를 따릅니다. 예시에는 `광고 예시` 표시를 붙이며 delivery를 발급하거나 노출·클릭 이벤트를 전송하지 않습니다.

일반 `/` 경로와 배포 빌드는 기존 B 광고 API의 `/api/ads` 응답, 유효시간, 이미지 로드, 가시성/클릭 측정을 사용합니다. 예시 모드는 광고 등록·예산 검증·게시 상태를 대신하지 않습니다. 최초 미리보기 단계에서는 제목·기간·우선순위·예산을 저장하지 않았습니다. 후속 로컬 등록과 연결 검증은 아래 절에 기록합니다.

검증: 원본/복사 이미지 SHA-256 일치, 프론트 TypeScript·Vite 빌드 통과, 로컬 개발 서버의 미리보기 URL과 이미지 두 개 HTTP 200을 확인했습니다. 현재 컴퓨터 사용 기능이 비활성화되어 브라우저 픽셀·클릭은 직접 검증하지 못했습니다. 실제 광고 API/측정, 운영 DB, 쿠팡 도착 페이지의 외부 동작은 이번 미리보기 검증 범위 밖입니다.

## 실제 로컬 광고 등록 — 2026-10-16

사용자 후속 요청으로 광고 예시 두 장을 `ads_sandbox_dev` MongoDB의 `ad_assets`와 `ads`에 **실제 레코드로 등록**했습니다. 기존 `AdsService.upload_asset`/`create_ad`의 검증·감사·멱등 경로를 사용했습니다. 공통 백엔드는 로컬 SQLite, 광고 API는 같은 로컬 MongoDB에 연결했고, 관리자 로그인은 로컬 `manage_ads` 권한으로만 준비했습니다. 비밀값과 로그인 자료는 Git 제외 `.local/ads-local-login.json`에 있으며 문서에 값을 기록하지 않습니다.

| 위치 | 제목 | 게시 기간(KST) | 우선순위 | 일일/전체 예산(토큰) | 이동 링크 | 광고 ID |
|---|---|---|---:|---:|---|---|
| 상단 | 카페 용품 광고 예시 | 2026-10-01 00:00 ~ 2026-12-31 23:59 | 10 | 1,000 / 10,000 | `https://www.coupang.com/` | `c1ee5db5-4eb0-47d0-b436-da4cfed09971` |
| 하단 | 카페 식물 광고 예시 | 2026-10-01 00:00 ~ 2026-12-31 23:59 | 5 | 500 / 5,000 | `https://www.coupang.com/` | `83606cdf-23b3-47d6-9223-14f128ccd329` |

로컬 `GET /api/admin/ads`는 ADMIN 로그인 상태에서 `ACTIVE` 두 건을 반환했습니다. 광고 예산 검증 작업은 `ads_checked=2`, `blocked=0`을 반환했고, `GET /api/ads?placement=top|bottom`은 각 광고의 delivery를 반환했습니다. 발급된 이미지 URL은 HTTPS 루프백 주소인데 개발 Vite는 HTTP 프록시이므로, [Banner.tsx](../../frontend/src/features/ad-banners/Banner.tsx)에서 **개발 모드의 127.0.0.1:8000 이미지 경로만** 동일 출처 프록시로 연결했습니다. 해당 이미지 응답은 JPEG 200을 확인했습니다. 배포 환경의 광고 URL은 바꾸지 않습니다.

확인 경로는 일반 공개 `/`와 관리자 `/admin/ads`입니다. 앞 절의 `/?ad_preview=1`은 계속 정적 이미지 미리보기이므로 실제 등록 자료 확인에는 사용하지 않습니다. 관리자는 `/login`에서 `.local/ads-local-login.json`의 계정으로 로그인합니다. 로컬 PC의 임시 서비스/DB이며 운영 DB·실제 집계·배포 완료를 뜻하지 않습니다. 브라우저 직접 클릭·화면 픽셀 수용은 컴퓨터 사용 기능이 비활성화되어 미검증입니다.
