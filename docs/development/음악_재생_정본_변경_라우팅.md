## 0. 최신 정정 — 기존 사용자 대시보드가 주진입

최신 사용자 지시로 `frontend/src/features/recommendation/PublicPage.tsx`의 기존 화면·추천/반응·제외/취소·별점·재설정·승인을 유지하며 곡별 YouTube 검색/검증 영상 열기를 추가합니다. 별도 `prototype/youtube-player/`로 사용자를 먼저 보내는 구조는 현재 주흐름에서 제외하고 개발 검수 도구로 보존합니다. 아래의 이전 iframe 구현/150 관측은 이력이며 네이티브 리다이렉션 오류를 뜻하지 않습니다.

현재 흐름은 **본인 불변 추천 결과 → 곡별 검색/검증 영상 URL → 사용자의 명시 새탭 이동**입니다. 실제 `youtube_video_id`와 VERIFIED 상태가 있을 때만 직접 열기를 제공하고 그 외에는 원곡명/아티스트 검색으로 안내합니다. 기존18개 `play_url`·점수·결과/승인/초안은 덮어쓰지 않으며 링크 클릭이 기존 피드백/광고/추천/Gemini 이벤트를 만들지 않습니다.

전체 임시 목록은 `youtube.com/watch_videos?video_ids=...`에 검증된 전곡 ID를 결과 순서대로 전달합니다. root는 실제2곡 URL이 첫 곡 `watch`와 YouTube 발급 `TL...` 목록으로 이동하고 Better의 시간 진행 뒤 Numb Little Bug으로 자연 전환되는 것을 확인했습니다. 중간 광고의 정상 건너뛰기 후 두 번째 곡 재생 UI를 관측했습니다. 앱에서 목록ID를 발명하거나 계정 내 저장·OAuth 완료로 표시하지 않습니다. 전곡 VERIFIED와 결과/선택/제외 상태 일치일 때만 전체 링크를 제공하고, 미저장/오류/생성 중/제외 미반영이면 새 선곡표를 안내합니다.2곡 부분 재생 관측은 전체47곡·연속3시간·광고 없는 무중단 재생·Chrome/Premium·물리적 음향 출력 검증이 아닙니다.
