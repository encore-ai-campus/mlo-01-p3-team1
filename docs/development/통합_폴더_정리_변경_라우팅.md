## 7. 남은 연결

A/B/C는 지역 조회 HTTP·날씨 provider 입력/응답·원문/코드의 저장 경계·PTY/시각 계약을 대조해야 합니다. B는 공유 로그인·guest·outbox/피드백과 광고 어댑터를, INF는 실행 위치·서비스 계정/네트워크·운영 gateway·기동/복구를 연결해야 합니다. `feature/infra`의 aws-infra/는 아직 develop에 반영되지 않았으며 이번 작업에서 따로 가져오거나 실행하지 않았습니다.

## 9. 버전 관리 인계 — 2026-10-16 추가 지시

사용자가 폴더 정리 완료 후 커밋·develop 푸시·새 통합 feature 브랜치 이동을 명시했습니다. 위 미커밋/미푸시 기록은 정리 완료 시점의 이력이며 이번 추가 지시로 버전 관리 반영을 진행합니다. CONTRIBUTING의 일반 PR 경유 기본안과 구분해 이번 develop 직접 푸시 요청을 따르며 보호 설정·CI·리뷰 승인 상태를 임의 변경하거나 승인 완료로 표시하지 않습니다.

사용자가 지정한 새 작업 브랜치는 `feature/integration`이며 develop의 폴더 정리 커밋에서 분기합니다. 처음 제안한 codex 접두어 이름은 사용하지 않습니다. `.gitattributes`로 제공 원문 6개의 자동 줄바꿈 변환을 제외해 체크아웃 이후에도 기록된 SHA-256을 유지합니다. 실제 .env·로컬 백업·캐시·DB·빌드/로그는 커밋하지 않습니다. 최종 커밋 식별자와 푸시·브랜치 이동 결과는 완료 보고에 남깁니다.
