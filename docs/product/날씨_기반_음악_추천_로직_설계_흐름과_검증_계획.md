# 날씨 ON/OFF 음악 추천 로직 흐름과 검증 계획

- 작성일: 2026-10-14
- 수정일: 2026-10-16
- 상태: [후보 산출 가이드](./카페_음악_추천_서비스_3차_컬럼_기반_추천_로직_가이드.md)의 구현·검증 계획입니다. 실제 코드/청취/성능 결과가 아닙니다.

## 흐름

1. 지역·날씨 반영 모드(ON 기본값)·보컬·빠르기·테마/장르를 정규화합니다. 테마·장르 0개/전체 선택은 ANY입니다.
2. 발행된 카탈로그의 등록/검수·보컬·중복 ID·양수 duration_ms·제외 초안을 검증합니다. ON에는 원본 정밀도 energy/acousticness/valence·mode와 유효 날씨가 필요하고 OFF에는 날씨/ON 전용 음향값을 요구하지 않습니다.
3. ON은 불변 카탈로그에 사전 계산된 다섯 날씨×PRIMARY/SUPPORT의 E/A 핵심≥20·W≥75 통과 점수를 읽어 곡을 모읍니다. PTY2/6은 비·눈 교집합이며, 직접 빠르기·장르 조건과 CSV 기반 선택 테마 적합 점수의 활성 선호 P_ON으로 S_ON=.75W+.25P_ON(미선택이면 W)을 계산합니다. 자동 적합 점수는 확정 mood 태그가 아닙니다. 날씨 누락·만료는 자동 OFF가 아닌 실패/보류입니다.
4. OFF는 테마별 energy·장르·mode·speed 40:40:5:15 정규화 P_OFF를 계산합니다. 직접 장르를 골랐다면 선택 장르 곡 100% 구성을 먼저 시도하고 전체 해당 후보에서도 불가능할 때만 실제 재생시간 80% 이상으로 완화합니다. 각 선택 장르는 다른 곡으로 대표합니다. 무선호 점수는 NULL이며 고정 시드로 탐색합니다.
5. 200곡 탐색 창에서 400→800→1,600→전체 적격까지 확장합니다. 두 모드 모두 176~184분만 허용하며 정확히180→가까운 초과→가까운 부족·동일 시간 가중 품질 순서입니다. OFF의 100% 장르 단계가 완화 단계보다 우선합니다. 자동 시간 단축은 없습니다.
6. 명시적 Gemini 재설정은 같은 모드의 적격 후보만 제공하고 서버가 등록 ID·필터·시간·부모 대비 신규 곡20% 내림(최소1곡)을 검증합니다. 실패하면 부모/초안/평가/승인을 보존합니다.
7. 작업·결과·승인·피드백에는 모드/입력/점수·시간·카탈로그 버전과 당시 곡·ON 날씨 근거를 불변으로 기록합니다. OFF의 날씨 패널 상태는 추천 판단과 분리합니다.

## 고정 검증

| 범위 | 검증할 사례 |
|---|---|
| 입력/모드 | 기본 생략 ON, 명시 OFF, 잘못된 코드 거부, 재설정 생략 상속/명시 변경409, 테마·장르 0개와 전체 선택 동치 |
| ON | 5날씨×2패턴, E/A=20±경계, W=75±경계, PTY2/6 양쪽 적격, PTY4/5 비·PTY7 눈, 날씨 만료/누락 차단, 수동 정수에서 역산 금지 |

| 시간/탐색 | 176/180/184분±1ms, 같은 시간 Q, 200창 실패 후 확장, 전체 후보 부족과 UNKNOWN 구분, 176분 미만 거부 |
