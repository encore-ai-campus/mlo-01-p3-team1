## 1. 제품 정의

뮤더는 카페·음식점 등 매장 운영자가 날씨 반영 여부와 음악 취향을 정해 약 3시간의 선곡표를 받고 조정하는 서비스다. 곡을 하나씩 찾아 목록을 구성하는 수고를 줄이는 것을 목표로 하며, 효과는 5절의 사용자 평가로 확인한다.

음원 파일 제공·자체 스트리밍은 제외하며, YouTube 외부 연결과 보조 iframe은 로컬 시험 범위에서 다룬다.

## 3. 기능 요구사항

상태의 `active`는 현행 적용 요구사항을 뜻하며, 구현 완료 여부는 나타내지 않는다. YouTube 항목의 `local_demo`는 로컬 보조 검증 범위이며 운영 배포 완료 조건에 포함하지 않는다.

‘사이클’은 같은 사용자 조건으로 묶인 추천 결과 계열이며, 그 안에서도 재설정·날씨 갱신으로 결과 버전이 바뀔 수 있다.

음악 원본의 운영 S3 보관은 사용자 결정에 따라 명시 보류한 상태다. 지정된 로컬 경로의 원본과 해시를 확인하며, 일반 S3 보관 경로와 이 보류 상태를 구분한다. 보류를 적용 범위 미합의나 S3 보관 성공으로 기록하지 않는다.

## 6. 실패·예외 처리

재설정 실패 시 기존 결과·승인·평가·제외 초안을 보존하고 규칙 추천으로 자동 대체하지 않는다. 아래 표는 상황별 안내와 사용자의 다음 행동을 정한다.

### 6-1. 입력·데이터 문제

| 상황 | 안내·처리 |

| 날씨 수집 실패 | ON은 보유 날씨가 유효하고 필요한 예보 구간을 충족하면 기준시각·수집 실패를 표시하고 추천을 허용하며 OFF는 날씨 실패로 추천을 막지 않는다. |

| 일반곡 판정 누락·발행 실패 | 신규 추천 자격을 우회하지 않고 재검수·새 버전 발행을 안내하며 기존 카탈로그와 과거 결과를 덮어쓰지 않는다. |
