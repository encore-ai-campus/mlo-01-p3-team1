# ADS — 3차 광고 인계 안내

- 작성일: 2026-10-14
- 수정일: 2026-10-14
- 상태: 구현에 사용할 문서 계약입니다. 광고 API·화면·MongoDB 설치·실제 측정은 미구현/미검증입니다.
- 사용자결정: 새음악문서우선으로음악은RDB4개/원본·백업S3, 로그는PostgreSQL, 광고업무는MongoDB입니다. 3차에는 음원 파일 자체를 저장하거나 재생하지 않습니다.

## 1. 읽는 순서와 기준

1. [광고 관리 간소화 원문](./04_광고_관리_간소화_인수인계서.md): 수령한 원문 보존 자료입니다. 업종 태그가 포함된 부분은 4차 확장 참고로 두며, 3차 범위는 최신 사용자 결정과 통합 인계를 따릅니다.
2. [통합·추가 인계](./05_광고_간소화_통합과_추가_인계.md): 3차 카페 전용 범위·내부 log_relay·예산/집계 연결입니다.
3. [광고 운영 정책](../../product/3차_광고_운영_회의_결정사항_목록.md): 유지할 단가·선정·노출·클릭·보관과 남은 결정입니다.
4. [화면·API·측정 인계](./01_광고_화면_API와_측정_계약.md): B의 관리/API와 C의 공개 배너 연결입니다.
5. [MongoDB 저장·로그 연결](./02_광고_MongoDB_저장과_로그_연결.md): 첫 세 컬렉션과 후속 참고 구조·원자성·로그 경계입니다.
6. [인프라·검증·완료 기준](./03_광고_인프라와_검증_인계.md) · [공통 저장 계약](../../product/3차_저장소_경계와_발행_계약.md): 실제 환경과 전체 저장 경계입니다.

3차는 카페 광고만 제공하며 업종 입력·태그·업종별 매칭을 넣지 않습니다. ads/ad_assets/ad_admin_changes 관리 단계 후 공개 측정과 주기 집계를 연결합니다. 업종별 확장은 [4차 광고 업종 매칭 가이드](./06_4차_광고_업종매칭_확장_가이드.md)에 분리했습니다. 미연결 지표는 연동 대기이며 실제0과 구분합니다. 수정/중단은 본문 version 비교, 공개 추천 입력은 동 단위 지역만 필수로 유지합니다.

제품 기능은 [서비스 흐름](../../product/카페_음악_서비스_기능_및_사용자_흐름_정리.md) 5-6/7-11, [설계도](../../product/카페_음악_서비스_구현_설계도.md) 7/9절, [공통 계약](../../product/3차_공통_개발_계약과_검증_기준.md) 3.6/3.7/4절에 연결합니다. 불일치는 최신 사용자 결정에 맞춰 함께 정정하며, 미정 운영값을 임의로 채우지 않습니다.

## 3. 반드시 구분할 저장과 상태

| 자료 | 기준 저장소 | 의미 |
|---|---|---|
| 광고·소재 메타데이터·delivery·최초 판정·반복 창·통계·예상 원장·관리 변경 | 광고 전용 MongoDB | 광고 업무의 기준 원본. 날씨 MongoDB와 DB 이름/권한/정리를 분리 |
| 광고 업무 로그의 사본·HTTP/오류/재처리 진단 로그 | PostgreSQL | 원본 광고 이벤트 ID로 연결. 로그 재전송이 광고 지표/예상 비용을 다시 증가시키지 않음 |
| 계정·ADMIN 세션·guest 문맥·추천 업무 상태 | PostgreSQL | 광고 DB로 이전하거나 광고 쿠키/별도 계정을 새로 만들지 않음 |
| 광고 이미지 바이트 | 광고 MongoDB ad_assets.image_bytes | 원본 Binary·MIME/크기/해시 보존, 교체는 새asset. 목록 JSON 바이트 제외·공개/미리보기 자격 검사. 실제 조회URL/캐시/정리는 INF/B/C 인계 |

`ad=null`(정상 광고 없음), 조회 실패, 측정 불가, 운영 제외는 다른 상태입니다. 광고 토큰 사용량은 실제 결제·guest 접근 토큰·delivery 인증 자료와 다릅니다.

## 4. 확정과 미정

확정 초기 정책은 한 광고 한 위치·동률 순환·중단 3초·50%/연속 1초·delivery별 각각 1회·새 delivery 노출 60초/클릭 300초·지연 300초·정적 이미지 2,000,000bytes·HTTPS·발생일 KST·90/365일 보관·예상 단가 8/5/15입니다. 처음에는 실제 잔액을 차감하지 않습니다.

이미지 MongoDB Binary 저장·첫 세 컬렉션·3차 카페 전용 범위·주기 통계 방식은 확정 개발 기준입니다. 예산 금액/일일 경계·허용 판정 지연/초과·집계 주기·재개 방식·delivery 수명·소재 변경 후 열린 delivery 처리·이미지 조회URL/정리·관리 권한은 후속 인계입니다. [통합 인계](./05_광고_간소화_통합과_추가_인계.md)와 [검증 인계](./03_광고_인프라와_검증_인계.md)에 담당/차단 범위를 기록합니다.
