# 3차 카페 광고 간소화 — 통합·추가 인계

- 작성일: 2026-10-14
- 수정일: 2026-10-14
- 기준: 사용자 수령 [간소화 원문](./04_광고_관리_간소화_인수인계서.md), 데이터 계약 `phase3-ads-data-20261014.3`
- 상태: 문서 적용입니다. 코드·DB·로그 전달·공개 배치 구현/운영 완료가 아닙니다.
- 범위 결정: 3차 광고는 카페 전용입니다. 업종 선택·태그 지정·업종별 매칭은 4차 확장으로 분리합니다. 수령 원문은 원문 보존용이며 3차 범위는 본 문서와 [4차 업종 매칭 가이드](./06_4차_광고_업종매칭_확장_가이드.md)를 따릅니다.

## 1. 구현 순서와 범위

간소화 원문의 관리 → 공개/측정 → 주기 집계/예산 순서는 유지합니다. 3차 범위에서 광고 대상은 카페로 고정하며, 단계별 태스크 ID와 직접 선행 관계도 유지합니다.

| 단계 | 구현/검증 | 완료로 볼 수 없는 범위 |
|---|---|---|
| 첫 관리 | `ads`, `ad_assets`, `ad_admin_changes` 세 컬렉션·MongoDB 이미지 Binary·등록/수정/중단·목록/필터/미리보기·멱등/동시성/감사·로그 전달 연결 | 공개 제공·실제 측정·토큰/예산 집계 |
| 다음 공개/측정 | 카페 광고의 위치·기간·게시 상태·소재·예산 자격, priority, 위치별 동률 순환·delivery·중단 3초·실제 측정 | 첫 관리만으로 AD-04~06 완료 불가 |
| 다음 집계/예산 | 최초 판정/예상 항목 원자 저장·주기 통계·예산 제공 제어·복구 | 실제 결제·구매·환불 추가 없음 |
| 4차 별도 확장 | 업종 선택·관리 태그·업종별 광고 매칭/순환 | 3차 API·DB·화면·수용 기준의 선행 조건 아님 |

미연결 통계는 `연동 대기`이며0으로 꾸미지 않습니다. 연결 후 실제0과 미연결을 구분하고 집계 범위·기준 시각·지연 상태를 표시합니다. 실시간 대시보드는 요구하지 않습니다.

## 2. 3차 카페 전용 계약

- 3차의 모든 광고 기록은 카페 대상입니다. `targeting_mode`, `target_tag_codes`, `tag_catalog_version`, `targeting_policy_version` 등 업종/태그 입력·저장 필드는 추가하지 않습니다. 사용자가 임의로 업종 필드를 보내면 공통 strict 입력 검증으로 거부합니다.
- 사용자에게 광고용 업종 선택·설문·로그인을 요구하지 않습니다. 광고 공개 조회에 필요한 guest 문맥은 중복 방지·소유 검증용이며 업종 정보를 담거나 추천 요청 여부를 조건으로 삼지 않습니다.
- 광고는 위치·기간·paused·소재·예산 자격을 검사한 뒤 높은 `priority` 순으로 제공합니다. 같은 priority에서는 상단/하단 위치별 round-robin을 적용합니다. 업종 태그 우선이나 ALL fallback은 없습니다.
- 최초 guest 발급과 추천 미요청 상태의 집계 기준은 유지합니다. 음악 추천에 필요한 지역 입력과 광고 대상 카페를 연결하지 않습니다.
- 보존한 업종별 확장은 [4차 광고 업종 매칭 확장 가이드](./06_4차_광고_업종매칭_확장_가이드.md)에서 다룹니다. 4차 구현을 위해 별도 코드·데이터 사전·입력 UI·공개 API·순환 상태·수용 정책을 결정해야 합니다.

광고 서비스에는 검증된 외부 ID만 참조하고 비밀번호·프로필·세션/guest 원문 토큰을 복제하지 않습니다. 공개 응답에도 사용자 ID/인증 원문을 노출하지 않습니다.

## 3. 세 컬렉션과 PostgreSQL 로그 연결

이미지 원본은 `ad_assets.image_bytes`에 MongoDB Binary로 보존합니다. 정적2MB와 BSON 전체 크기를 검증하고 목록 JSON에는 바이트를 넣지 않습니다. 이미지 교체는 새 asset, 미리보기는 인증된 조회, 공개 이미지는 게시 자격을 검사하는 별도 조회 경계로 제공합니다. 실제 URL·캐시·미사용/백업 정리는 INF/B/C가 인계합니다. Django ORM으로 MongoDB를 관리하지 않고 별도 어댑터와 replica set 트랜잭션을 유지합니다.

별도 outbox 컬렉션을 첫 단계에 추가하지 않도록, 다음은 기존 공통 로그 계약을 연결하는 **기술 보완 기준**입니다. 수령 원문에 이미 확정된 필드라고 취급하지 않습니다.

- 관리 변경/멱등 성공 기록과 함께 `ad_admin_changes`에 `log_relay` 보조 객체를 같은 MongoDB 트랜잭션으로 저장합니다. `log_event_id`는 해당 `log_id`에서 안정적으로 정하고 불변 `payload`/`payload_hash`, `status=PENDING/SENT`, `attempt_count`, `next_retry_at`, `last_error`, `sent_at`을 관리합니다. 실제 처리 중 claim/lease 방식은 B가 동시성 검증 후 고정합니다.
- payload는 당시 관리자/광고/asset·operation·changed·시각·version·request_id·is_test와 필요한 참조입니다. 이미지 원본·개인 인증 토큰·비밀번호는 넣지 않습니다. relay 상태를 변경해도 감사 snapshot과 최초 멱등 응답을 바꾸지 않습니다.
- PostgreSQL에 `UNIQUE(log_event_id)`로 저장/동일 payload를 확인한 뒤 SENT로 표시합니다. 저장 후 표시 전 종료는 같은 ID로 재전송하며 같은 ID의 다른 payload는 경보입니다. PostgreSQL 장애 때는 pending을 유지하고 재시작 후 다시 전달합니다.
- 인증 서비스 장애는 관리 변경 차단, 로그 사본 전달 지연은 커밋된 업무 결과 유지로 구분합니다. 두 DB를 하나의 원자 트랜잭션으로 설명하지 않습니다. relay는 광고 통계/토큰을 다시 계산하지 않습니다.
- pending과 감사/멱등 보관 의무가 남은 자료는 삭제하지 않습니다. 응답 만료와 감사 보관은 구분하며 TTL만으로 참조 보호를 대신하지 않습니다.

## 4. 주기 통계와 예산

단가8/5/클릭추가15·50%/1초·delivery각각1회·반복60/300초·지연5분·발생일KST는 유지합니다. 후속 측정에서 최초 판정과 예상 항목은 원자 저장하고 배치는 그 항목의 합계를 갱신합니다. 재실행 시 범위 재계산/교체 또는 원본 처리 추적으로 중복 합산을 막습니다. 지연/자정/90일 원본과365일 원장 보관을 검증합니다.

관리자 통계가 배치여도 예산 소진 시 신규 제공 중단은 유지합니다. 예산값·일일 경계·집계 주기·허용 판정 지연/초과는 PL/B 인계입니다. 엄격한 중단은 제공 경로의 최신 사용량 판정/동시 제어가 필요하고 지연 허용 방식은 명시한 한도 안에서 검증합니다. 미결정이면 fixture만 사용하고 실시간 상한이나 무제한 예산을 보장하지 않습니다.

## 5. 추가 수용 사례와 담당

| 사례 | 기대 결과/담당 |
|---|---|
| 첫 관리 저장·이미지 변경·재전송/실패 | 세 컬렉션 원자성·기존 바이트 보존·감사/응답 일치 / B·INF |
| 위치·기간·paused·소재·예산 자격 | 부적격 광고 제외, 위치별 상위 priority 후보 제공 / B·C |
| 같은 위치·priority 동률 광고 | top/bottom별 round-robin, 중복 delivery에서 커서 미전진 / B |
| 업종/태그 관련 필드 포함 요청 | 3차 strict 입력 검증에서 거부, 업종별 자료/상태 생성 없음 / B·C |
| 미연결 통계·연결된 실제0 | `연동 대기`와0 구분 / B |
| PostgreSQL 저장 후 SENT 전 종료 | 같은 `log_event_id` 재전송·중복 로그 없음 / B·INF |
| 로그 지연·관리 인증 장애 | 전자는 pending 유지, 후자는 관리 요청 차단 / B |
| 집계 재실행·지연/자정·예산 경계 | 예상 항목 중복 없음·발생일 유지·채택 예산 모드 대조 / B·PL·INF |

B는 관리 API/화면·MongoDB·감사/멱등·로그 relay·후속 측정/집계, C는 공개 배너·카페 전용 공개 배치, INF는 독립 API/MongoDB·원본 이미지 조회·replica set/권한/복구, PL은 운영/예산 문구와 수용을 맡습니다. 실제 구현/설치/GitHub 변경 완료를 뜻하지 않습니다.
