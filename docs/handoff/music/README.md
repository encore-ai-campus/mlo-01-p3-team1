## 3. 담당과 남은 인계

C는CSV 변환·음악RDB/조회·규칙/Gemini·당시값공급, B는관리/검수 API·공통상태/불변기록·트랜잭션연결, PL은실제mood/악기/검수·테마세부정렬·혼합최초speed 결정취합, A는원래PTY/SKY·예보유효구간, INF는실제DB/DDL·접속/발행/원본/백업환경을연결합니다. 인원과기존작업ID는바꾸지않습니다.

ON/OFF의 수식·표·시간 규칙은 최신 가이드에 있습니다. 실제 원본 정밀도 valence/energy/acousticness의 카탈로그 연결·청취자료·혼합 PTY2/6 speed 초기값 수용·explicit 미확인 세부·DB 제품/물리 DDL/접속·불변 발행/보관·성능/청취 목표는 [확인 목록](../../product/3차_사용자_확인과_담당자_인계_목록.md)에 남깁니다.

[이전16개수동기준](./archive/음악_분류_컬럼_정의_16개_수동_보관.md)은이력입니다. 현행자료와동시에적용하지않습니다.
