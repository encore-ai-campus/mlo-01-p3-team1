# 02. 날씨 데이터 규격과 정제

수정일: 2026-10-14. 원천은 메모리에서 해석하고 Kafka JSON으로 전달. 파일 미보관.
실황·초단기·SNO는 쉼표 숫자 텍스트, KIM은 ix·iy·lon·lat·value CSV.
22.3,21.8,...는 여러 격자의 같은 항목. 한 지역의 여러 항목 나열이 아님.

## 항목

| 코드 | 의미·단위 |
|---|---|
| T1H | 기온 ℃ |
| REH | 상대습도 % |
| RN1 | 1시간 강수량 mm |
| WSD | 풍속 m/s |
| UUU·VVV | 동서·남북 바람 성분 m/s, 음수 가능 |
| VEC | 풍향 0~360도 |
| PTY | 강수 형태 코드 |
| SKY | 하늘 상태 코드 |
| LGT | 낙뢰 예보, API 표기 kA. 원 수치 유지 |
| POP | 강수확률 %, 실제 강수와 구분 |
| SNO | 1시간 신적설 cm, 예보 보완 |
| TCDC | KIM 구름량. 원문 0~1 → % |

실황 8항목: T1H·REH·RN1·WSD·UUU·VVV·VEC·PTY.
초단기: 위 8개 + SKY·LGT·POP. 현재 실황에 SKY 없음.
PTY: 0 없음 / 1 비 / 2 비·눈 / 3 눈 / 4 소나기 / 5 빗방울 / 6 빗방울·눈날림 / 7 눈날림.
실황 허용 0·1·2·3·5·6·7, 초단기 0~7. 8은 허용하지 않음.
SKY: 1 맑음 / 3 구름 많음 / 4 흐림. PTY=0을 맑음으로 바꾸지 않기.

## 품질·시간

raw 원래 값 / value 정규값 / unit 단위 / status 품질.
기본 -99·-900 이하·900 이상은 NULL. 실제 0 유지. KIM에 같은 결측 규칙 적용 없음.
valid / missing / invalid_code / out_of_range / invalid_value 등으로 구분.
KIM 0~1 검사 후 100배. LGT 임의 밀도 환산 없음.
issued_at 발표 / target_at 대상 / received_at 수신. 현재 코드 한국 시간 +09:00.
공통 API 계약의 UTC Z 표기와 같은 시각으로 변환 필요. 인계 시각 형식 통일 전.
KIM UTC 요청 변환. SNO·KIM은 같은 격자·대상 시각에만 연결.
RN1·SNO 실제 누적 경계 미확인. 10분 자료 6개 단순 합산 금지.
서비스 sky_state_v1: SKY 기본 분류 + 같은 시각 KIM 세분화. 원래 값 보존.
state·label·status·target_at·inputs 제공. agree / sky_only / kim_only / conflict / unavailable.
현재 하늘은 한국 현재 정시 대상의 예측 기반 추정. 10분 구름 관측으로 표시 없음.
features: 계절·체감 추정/적용 상태·눈 강도·daylight·강수 그룹·관측 유효 상태.
최종 방향: 정규값·품질·하늘 분류·공통 특징을 ES에 적재, 음악·화면에서 같은 값 조회.
현재는 dashboard/server.py 조회 단계에서 guidance·music_weather 계산. ES 적재 연결은 후속 작업.
최종 필드명·인덱스명은 예시 JSON으로 인계. 조회 시 만료·필요 시간 범위는 다시 검사.
available_at: 포함 자료 실제 received_at의 최댓값. 원래 값은 보존, 만료 사용값은 NULL.

## JSON 예시 — 설명용

```json
{"schema_version":1,"source":"odam","kind":"observation","category":"T1H",
 "issued_at":"2026-10-14T09:00:00+09:00","target_at":"2026-10-14T09:00:00+09:00",
 "received_at":"2026-10-14T09:06:00+09:00","raw_path":null,
 "mapping_version":"2026-07-01","readings":[{"nx":58,"ny":125,"raw":"22.30"}]}
```

실제 이벤트에는 event_id·source_hash·part·spatial_basis도 포함. event_id는 재전송 식별.
raw_path=null은 원문 파일 없음. raw 문자열은 값의 표현이며 전체 응답 파일과 구분.
