# 06. 로컬 실행과 인계

수정일: 2026-10-14. C:\project3에서 작업.
코드 작성·시험과 실제 클러스터 운영 연결 구분.
확정 방향: PostgreSQL 매핑 / ES 최신·공통 특징·수집 로그 / 개인 로컬 정제 이력.
운영 연결·Kafka/로그 보관 기간은 미정. 이번 문서 갱신으로 코드·DB가 변경된 것은 아님.

compose.stream.yaml로 Kafka·Spark·ES 실행. MongoDB 서비스 실행 없음.
기존 storage.py의 MongoDB 어댑터는 과거 시험용.
새 수집 실행이 미정 저장소 연결 완료를 뜻하지 않음.

## 수집

키 조회 KMA_API_KEY → .env. 키만 저장, Git 제외.
Kafka 준비 후 실행:

```powershell
python -X utf8 -m pipeline.run_local --bootstrap 127.0.0.1:19092 --topic weather.stream.local.v1
```

상태 codex/stream_runtime/state.json: 큐·완료·실패·일일 사용량.
requests.jsonl은 호출별 메타데이터만. raw/gzip/전체 이벤트 파일 생성 없음.
현재 호출 결과·소요 시간 기록. 공용 pipeline-logs-v1 전송·단계별 결과 연결은 후속 작업.
중지: 같은 폴더 stop.flag 생성. 재시작 전 해제.
Windows msvcrt / Linux fcntl 실행 잠금. 두 서버 주·대기 제어는 인프라 협의.
PC/프로그램 종료 시 수집 중지. 운영 자동 시작·24시간 복구 검증 미완료.
전송 실패 요청은 재수집. Kafka 기간 이후 원천 복구 보장 없음.

## 조회

```powershell
$env:WEATHER_INDEX='weather-stream-current-v1-local'
python -X utf8 dashboard/server.py --port 8765
```

http://127.0.0.1:8765/ . ES_URL·WEATHER_INDEX 환경변수 설정 가능.
기본 접속은 과거 시험 ES. ES가 없으면 연결 오류 표시.
/api/weather: region·weather·guidance·music_weather. 조회마다 기상청 호출 없음.
현재 서버가 guidance·music_weather 계산. 최종 ES 공통 특징 적재와 실제 서비스/음악 연결은 후속 통합.
화면은 1분마다 저장 자료 조회. 자료 갱신 실패 시 기존 시각 유지, 만료 자료는 현재값으로 사용 제외.
