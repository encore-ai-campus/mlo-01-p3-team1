# 05. 날씨 분류와 전달 기준

수정일: 2026-10-14. 원래 값 보존, 서비스 특징 weather_features_v0.3 별도 제공.
음악 점수·곡 선택·Gemini 호출은 음악 담당.

## 하늘 — sky_state_v1

같은 nx·ny·대상 시각의 SKY 기본 분류 + KIM 구름량 세분화. 서비스 기준.

| SKY | KIM | 표시 |
|---|---|---|
| 맑음(1) | 0~10% | 구름 거의 없음 |
| 맑음(1) | 10% 초과~50% | 구름 조금 |
| 구름 많음(3) | 50% 초과~85% 미만 | 구름 많음 |
| 흐림(4) | 85% 이상~95% 미만 | 흐림 |
| 흐림(4) | 95~100% | 구름으로 거의 덮임 |

불일치: SKY 유지·conflict. KIM 없음: SKY만. SKY 없음: KIM 단독 추정. 둘 다 무효: 판단 불가.
코드 가중 평균·시간 보간 없음. 구름 두께·어두움 판단 없음. 0% 정상.
14:20 현재 하늘 → 14시 대상 예측 기반 추정. 위성 구름 관측 수집 제외.
예보 회차 교체 후 현재 정시 SKY 유지. SKY 발표 120분·KIM 720분 개발 만료.

## 강수·눈·바람

| 항목 | 서비스 기준 |
|---|---|
| PTY | 비·눈·혼합·소나기·빗방울·눈날림 원래 현상 유지 |
| 비 1시간량 | 양수~3mm 미만 약함 / 3~15 보통 / 15~30 강함 / 30 이상 매우 강함 |
| 눈 예상 1시간량 | 양수~0.5cm 미만 약함 / 0.5~1 보통 / 1 이상 강함 |
| 바람 | 4m/s 미만 약함 / 4~9 다소 강함 / 9 이상 강함 |
| 낙뢰 | LGT=0 없음 / 양수 예측 있음 |

눈 등급은 신적설 SNO 기반 서비스 표현. 실제 적설·폭설·예쁘게 내림 판단 아님.
SNO 발표 300분 개발 만료. 실제 0·결측 구분, RN1/SNO 누적 구간 경계 확인 중.
현재 강수·기온·바람은 유효한 10분 실황만. 만료 시 현재 수치·판단 제외, 원래 값은 상세 보존.

## 계절·체감 — comfort_v1

계절: 3~5월 봄 / 6~8월 여름 / 9~11월 가을 / 12~2월 겨울.
추움·선선함·온화함·더움 경계: 봄/가을 10·18·26℃, 여름 18·24·30℃, 겨울 5·10·20℃.
체감 추정이 있으면 해당 값, 없으면 기온으로 분류. 평년 대비 분석·공식 위험 등급 아님.
습도: 40% 미만 건조 / 40~70% 미만 보통 / 70% 이상 습함.
산식 계절: 5~9월 여름, 10~4월 겨울. 표현용 4계절과 구분.

```text
겨울 = 13.12 + 0.6215T - 11.37V^0.16 + 0.3965TV^0.16
여름 = -0.2442 + 0.55399Tw + 0.45535T - 0.0022Tw² + 0.00278TwT + 3.0
Tw = T atan(0.151977√(RH+8.313659)) + atan(T+RH) - atan(RH-1.67633)
     + 0.00391838 RH^1.5 atan(0.023101RH) - 4.686035
```

T=℃, RH=%, V=풍속×3.6(km/h), atan=라디안. 겨울 T≤10·풍속≥1.3m/s에서 적용.
여름은 서비스 보수 범위 T=20~50·RH=5~99에서 적용. 범위 밖/입력 누락은 체감 NULL.
WSD 평균 구간 미확인·습구 근사이므로 ‘체감 추정’. 일 최고/최저 체감이 아닌 해당 시각 계산.
[기상청 산식](https://data.kma.go.kr/climate/windChill/selectWindChillChart.do?pgmNo=111) / [Stull 원문](https://doi.org/10.1175/JAMC-D-11-0143.1)

## 주야간·강수 알림

격자 대표 위경도·날짜로 일출/일몰 추정. 일출 이상·일몰 미만 낮, 나머지 밤. 맑은 밤은 달 표시.
[NOAA 계산식](https://gml.noaa.gov/grad/solcalc/solareqns.PDF). 추가 API 없음. 지형·건물의 실제 시야 차이 제외.
알림: 브라우저가 연속 확인한 유효 실황의 강수 시작·종료·비/눈 종류 변화. 첫 조회는 기준만 설정.
같은/과거 관측 재알림 없음. 관측 간격 20분 초과·결측·만료는 시작/종료로 판단하지 않음.
격자별 기준·알림 닫기 상태는 브라우저 저장. 같은 회차 닫으면 재등장 없음. 알림 20분 표시.
대시보드 안 알림이며 별도 푸시·공식 특보·플레이리스트 자동 교체와 별개.

## 음악 전달·품질

대시보드와 동일한 current_features·current_sky·시간별 features. 원래 코드·값·발표/대상/수신 보존.
현재 API 조회 단계 계산. 최종은 ES에 공통 계산 결과 적재 후 음악·화면 담당 조회. 아직 이관 전.
화면은 현재 날씨 + 앞으로 3시간. 수집한 6시간 예보 중 요청 시각에 필요한 범위 사용.
추천 시 사용한 날씨 묶음은 추천 결과와 함께 고정 보관. 재석은 묶음 제공, 추천·백엔드 담당은 저장 연결.
최신 날씨가 바뀌어도 이미 생성한 선곡 근거를 덮어쓰지 않음. 담당 간 저장 연결은 통합 시 확정.
사용값에서 만료 보완 제외. available_at은 포함 자료의 실제 수신 완료 시각, 품질·유효성과 구분.
PTY=0: 하늘에서 clear/cloudy/overcast / 1·4·5: rain / 2: rain_snow / 3: snow.
PTY=6·7은 mapping_unresolved·후보 제공. 음악 결합 비율 미정. 비·눈이 있어도 sky 보존.
앞 180분~최대184분 확인. service_hour_ending_v1은 서비스 구간 규칙, 누적 구간 확정 의미 아님.
ready는 자료 준비 상태. 음악 승인·추천 성공과 별개. 기준 수치는 runtime_config.json에서 관리.
