# 05. 날씨 분류와 계절 기준

- 수정일: 2026-10-13
- 프로젝트 적용 결정: 같은 네트워크의 로컬 Kafka/Spark 클러스터에서 새 날씨 파이프라인을 구현하고 최종 AWS로 이전합니다. 원문은 로컬과 S3에 함께 보관합니다. S3 실패 재시도·해시/사본 상태·보관/재처리 상세는 [최신 구현 가이드](../../product/3차_구현_결정과_익명문맥_원문보관_가이드.md)를 따릅니다.
- 화면은 날씨 패널만 유지하며 별도 강수 카드/X/닫기 상태는 제거합니다. 소나기·빗방울은 비, 기본 눈날림은 눈+구름많음 적합도 결합이며 비율/PTY6은 미정입니다. Gemini 재설정도 서버의 같은 적격 기준을 따릅니다. 원본 PTY 표현은 보존합니다.
- 아래 기존 로컬 시험 코드/경로/수치 설명은 인계 출처의 이력입니다. 현재 저장소에 코드가 구현됐거나 AWS/S3 업로드가 완료됐다는 뜻은 아닙니다.

분류 규칙은 `weather_features_v0.1`. 원래 수치를 유지하고 결과만 별도 생성.
Spark 저장 경로는 정규값·품질 제공까지 적용. 로컬 대시보드는 같은 분류 함수로 안내 문구 생성.

## 항목별 분류

| 구분 | 현재 규칙 |
|---|---|
| 강수 형태 | PTY의 비·눈·혼합·소나기·빗방울·눈날림 유지 |
| 하늘 상태 | PTY=0일 때 SKY 해석. 실황에 SKY 없으면 판단 불가 |
| 비의 양 | 양수~3mm 미만 약함 / 3~15 보통 / 15~30 강함 / 30 이상 매우 강함 |
| 눈의 양 | 양수~1cm 미만 보통 / 1cm 이상 많음 |
| 바람 | 4m/s 미만 약함 / 4~9 다소 강함 / 9 이상 강함 |
| 낙뢰 | LGT=0 예측 없음 / 양수 예측 있음 |

RN1·SNO는 1시간량. 순간 폭우·폭설 강도로 단정하지 않기.
강수량 0·결측은 양수 등급과 별도. PTY에 비가 있고 RN1=0이어도 형태를 유지.
현재 눈의 양에 예보 SNO 사용 금지. 눈의 양이 없어도 PTY·풍속 제공.
비+강한 바람 등 조합 생성. 예쁜 눈·눈 결정 모양·눈보라로 단정하지 않기.

## 구름·보완 자료

기본 SKY 유지, KIM 구름량은 % 보완값으로 별도 전달.
KIM 원본 비율 0.7 → 70%. 구름량 세부 등급은 현재 출력하지 않음.
기본값에 0.9, KIM에 0.1을 곱하는 가중 평균 없음. 기본 자료 우선 + 보완값 별도 구조.
POP는 강수확률. 높은 확률을 실제 비 발생으로 바꾸지 않기.

## 시간 기준

같은 nx·ny·대상 시각의 보완 자료만 연결. 미래 예보로 과거 관측 대체 금지.
as_of를 지정하면 그 시각 이후 발표한 기본·보완 자료 제외.
ML 시점 판단에는 실제 received_at도 함께 사용. replay 수신 시각은 과거 가용 시각으로 사용 금지.

## 계절·체감

실제 기온·습도·풍속·한국 시간 기준 월 유지. 고정 온도 경계로 계절 등급 생성 없음.
체감온도·기온 등급·습도 등급은 현재 NULL.
공식 체감온도 산식에는 계절·입력 풍속의 평균 시간 등 별도 조건 존재. 현재 WSD만으로 공식 체감값 단정 금지.

## 대시보드 안내

현재는 실황 PTY·풍속 기준, 예보 안내는 지금 이후 3시간 안의 대상 시각 기준.
비·눈·혼합·소나기·강풍·낙뢰 안내. 강수확률은 실제 %로 표시, 비 발생으로 단정 금지.
맑음·흐림 안내에는 예보 대상 시각 표시. 기온은 실제 ℃ 범위만 제공.
결측·지난 예보는 안내 근거에서 제외. 표시된 시각 밖의 오늘 밤·내일 날씨로 확대 금지.

## 출력 예시

| 입력 | 결과 |
|---|---|
| PTY=1, RN1=2, WSD=10 | 비 / 약한 1시간 강수량 / 강한 바람 |
| 예보 PTY=3, SNO=0.5, WSD=2 | 눈 / 보통 눈 / 약한 바람 |
| PTY=0, SKY=4 | 흐림 |
| 실황 PTY=0, SKY 없음 | 강수 없음 / 하늘 상태 판단 불가 |

설명용 숫자. 강수·바람 등급은 서비스용 규칙, PTY·SKY는 기상청 코드 해석.
