# 02. 날씨 데이터 규격과 정제

- 수정일: 2026-10-13

## API 원문 → 공통 JSON

실황·초단기·SNO는 쉼표로 나열된 숫자 텍스트.
`22.30, 21.80, ...`는 서로 다른 격자의 같은 항목 값. 한 지역의 기온·습도 나열이 아님.
항목과 시각은 요청 정보로 구분. 배열 위치로 nx·ny 부여.

KIM은 `ix,iy,lon,lat,value` CSV. `value`는 구름량 0~1 비율.
Collector가 원문을 보관하고 출처·항목·시각·값 묶음을 JSON으로 변환.
Spark가 우리 격자를 선택하고 정규값 생성. 원본 값은 유지.

## 항목 사전

| 코드 | 의미 / 전달 단위 | 읽는 법 |
|---|---|---|
| T1H | 기온 / ℃ | 22.3 → 22.3℃ |
| REH | 상대습도 / % | 70 → 70% |
| RN1 | 1시간 강수량 / mm | 2 → 1시간량 2mm |
| WSD | 풍속 / m/s | 5 → 초당 5m |
| UUU·VVV | 동서·남북 바람 성분 / m/s | 음수도 정상 가능 |
| VEC | 풍향 / 도 | 0~360 |
| PTY | 강수 형태 / 코드 | 3 → 눈 |
| SKY | 하늘 상태 / 코드 | 4 → 흐림 |
| LGT | 낙뢰 예보 수치 / API 표기 kA | 0은 예측 없음, 양수는 낙뢰 예측 |
| POP | 강수확률 / % | 70 → 확률 70%. 강수량 아님 |
| SNO | 1시간 신적설 / cm | 0.5 → 새로 쌓일 눈 0.5cm |
| TCDC·tcld | KIM 예측 구름량 / % | 원본 0.7 × 100 → 70% |

실황: PTY·REH·RN1·T1H·UUU·VEC·VVV·WSD.
초단기: 위 8개 + SKY·LGT·POP. 실황에 SKY 없음.
SNO·KIM은 보완 자료. 위성·안개·특보 수집 제외.

KIM은 원본 0~1 범위를 검사하고 %로 변환. `raw_unit=fraction`, `unit=%`.
이미 %인 숫자를 비율로 추측해 받지 않기. 1보다 큰 원본은 범위 오류.
LGT는 API의 수치를 보존. 밀도로 추정 환산하거나 코드 등급으로 해석하지 않기.

## PTY·SKY

| PTY | 의미 |
|---|---|
| 0 | 강수 없음 |
| 1 | 비 |
| 2 | 비·눈 |
| 3 | 눈 |
| 4 | 소나기 |
| 5 | 빗방울 |
| 6 | 빗방울·눈날림 |
| 7 | 눈날림 |

실황 허용: 0·1·2·3·5·6·7. 초단기: 0~7. 단기: 0~4.
PTY 8은 허용하지 않음. 강수 형태 코드와 강수량 등급은 별개.
SKY: 1 맑음 / 3 구름 많음 / 4 흐림. 0·2는 허용하지 않음.
PTY=0만 보고 맑음으로 판단하지 않기.

## 단위·결측·시간

기본 격자의 -99 및 -900 이하·900 이상은 결측 NULL. 이 규칙을 KIM에 일괄 적용하지 않기.
실제 0은 유지. 결측을 0·맑음으로 대체하지 않기.

`measurement`: raw 원문 / value 정규값 / unit 단위 / status 품질.
status: valid 정상 / missing 결측 / invalid_code 코드 오류 / out_of_range 범위 밖 / invalid_value 숫자 해석 불가.

예시: RN1 `raw="0.00" → value=0, valid`. `raw="-99.00" → value=null, missing`.
KIM `raw="0.7", raw_unit="fraction" → value=70, unit="%", valid`.

issued_at 발표·자료 시각 / target_at 대상 시각 / received_at 수신 시각. +09:00 통일.
KIM 요청 시각은 UTC에서 한국 시간으로 변환. hf는 발표로부터 몇 시간 뒤인지 의미.
실황 target_at은 관측 대상 시각. 예보와 관측 구분.

SNO·KIM은 같은 nx·ny·대상 시각의 예보에만 연결. 기본 SKY 덮어쓰기·임의 시간 보간 없음.
RN1·SNO는 1시간량. 10분 응답 6개 단순 합산 금지. 누적 시작·종료는 확인된 범위만 사용.
